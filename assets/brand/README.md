# Brand assets

ضع هنا أصول الهوية الرسمية للمتجر المستخدمة في الموقع.

الملفات المقترحة:
- `logo.png` — اللوجو الأساسي.
- `favicon.png` أو `favicon.svg` — أيقونة الموقع.

بعد رفع اللوجو، اختَر المسار `assets/brand/logo.png` من إعدادات الموقع في لوحة الإدارة، أو عدّل مسار الشعار من Website → Customizer.

لا تضع مفاتيح سرية أو ملفات بيانات حساسة داخل هذا المجلد.
